# Verified Iterative Root-Finding (M4)

A reproducible research project implementing and analysing a fourth-order
iterative method for scalar nonlinear equations, with a complete LaTeX
manuscript, tests, and benchmarks.

## Research question
Can a simple two-step correction to Newton's method achieve fourth-order
convergence while using one evaluation of $f$ and one of $f'$ per
iteration?

## Contribution
- A specific fourth-order method (M4) with a clean convergence proof.
- Symbolic verification of the order via Taylor expansion.
- Open-source implementation with tests and reproducible benchmarks.
- A complete manuscript (`paper/main.tex`) targeting IMA Journal of
  Numerical Analysis (OUP).

## Status of findings
Technical claims verified symbolically and numerically. Novelty is
incremental (see `research/novelty_assessment.md`). Not peer-reviewed.
